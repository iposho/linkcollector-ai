# Быстрая установка

## Шаги для локальной проверки расширения:

1. **Установите зависимости:**
   ```bash
   npm install
   ```

2. **Создайте файл `.env.local` с вашим Cerebras API ключом:**
   ```bash
   echo "CEREBRAS_API_KEY=ваш_ключ_здесь" > .env.local
   ```

3. **Соберите расширение:**
   ```bash
   npm run build
   ```

4. **Загрузите в Chrome:**
   - Откройте `chrome://extensions/`
   - Включите "Режим разработчика"
   - Нажмите "Загрузить распакованное расширение"
   - Выберите папку `dist`

5. **Настройте Google Apps Script:**
   - Следуйте инструкциям в README.md
   - Скопируйте URL веб-приложения в настройки расширения

Готово! Расширение готово к использованию.

# Установка (для разработчика)

Этот файл описывает установку **из исходников** и полезен для локальной проверки/разработки.

Если вы хотите инструкцию “как пользоваться расширением” (без сборки), откройте:

- `docs/USER_GUIDE_RU.md`

---

## Быстрый старт

1. **Установите зависимости**

```bash
npm install
```

1. **Соберите расширение**

```bash
npm run build
```

1. **Загрузите в Chrome**

- Откройте `chrome://extensions/`
- Включите **Режим разработчика**
- Нажмите **Загрузить распакованное расширение**
- Выберите папку `dist`

1. **Настройте хранилище**

- Для Google Sheets настройте Apps Script URL (подробно в `docs/USER_GUIDE_RU.md`)
- Для Notion настройте Token + Database ID (подробно в `docs/USER_GUIDE_RU.md`)

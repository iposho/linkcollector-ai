1) Как начать пользоваться (3–5 минут)

Шаг 1. Установите расширение

Если расширение уже установлено — пропустите этот шаг.

  1. Откройте chrome://extensions/
  2. Включите Режим разработчика
  3. Нажмите Загрузить распакованное расширение
  4. Выберите папку расширения (обычно dist, если вам передали готовую сборку)

Шаг 2. Настройте хранилище

Откройте расширение → Настройки (⚙️) → Хранилище ссылок.

Вариант A. Google Sheets

Нужен URL веб‑приложения Apps Script, который заканчивается на /exec.

  1. Сделайте копию таблицы по кнопке Шаблон таблицы в справке расширения
  2. В таблице откройте Расширения → Apps Script
  3. Deploy → New deployment и выберите Web app
  4. Execute as: Me, Who has access: Anyone
  5. Скопируйте Web app URL вида https://script.google.com/macros/s/.../exec
  6. Вставьте URL в настройках расширения в поле Google Apps Script URL и нажмите Сохранить
Проверка: откройте “Справка и FAQ” → “Диагностика” → Проверить Script URL.

Вариант B. Notion

  1. Создайте Integration Token на notion.so/my-integrations
  2. Создайте базу данных в Notion и подключите к ней интеграцию (⋯ → Connections)
  3. Скопируйте Database ID (обычно UUID из ссылки на базу)
  4. В расширении: Настройки → Notion → вставьте Token и Database ID
  5. Нажмите Проверить соединение и затем Сохранить

Шаг 3. Сохраните первую ссылку

  1. Откройте нужную страницу
  2. Нажмите иконку расширения
  3. Если нужно — нажмите Захватить страницу
  4. Проверьте категорию, теги и заметки
  5. Нажмите Сохранить ссылку

2) Ежедневное использование

  • Сохранить вкладку: открыть вкладку → иконка расширения → (при необходимости) “Захватить страницу” → “Сохранить ссылку”.
  • Сохранить ссылку через контекстное меню: правой кнопкой по ссылке → “Сохранить…” (если пункт доступен).
  • Управление: “Открыть список” → поиск/редактирование/удаление/импорт/экспорт.

3) ИИ‑анализ

Включение: Настройки → ИИ‑анализ → “Включить ИИ‑анализ”. Выберите провайдера и вставьте API‑ключ, затем нажмите “Проверить соединение”.

  • Gemini: aistudio.google.com/apikey
  • Groq: console.groq.com/keys
  • OpenRouter: openrouter.ai/settings/keys
  • SambaNova: cloud.sambanova.ai/apis

ИИ предлагает черновик (категория/теги/резюме) — вы всегда можете исправить вручную.

Если что-то не работает

  • “Сохранение недоступно”: не настроен Script URL (Google Sheets) или Token/Database ID (Notion).
  • “Не удалось захватить данные страницы”: страницы chrome://… и страницы расширений недоступны.
  • Script URL отвечает HTML: чаще всего скопирован не тот URL или доступ не выставлен “Anyone/Все”.
Совет: в расширении есть “Справка и FAQ → Диагностика”, где можно проверить Script URL / Notion / ИИ‑ключ.

Приватность

Настройки, категории и список ссылок хранятся локально в Chrome. Очистить всё можно через “Настройки → Очистка кэша”.
